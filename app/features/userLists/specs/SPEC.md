# User Lists

## Intent
UI mínima para agregar y listar nombres de usuario en memoria.

## In scope
- Campo con label y botón para agregar un nombre
- Lista de usuarios con botón para eliminar cada uno

## Out of scope
- Persistencia remota o en localStorage
- Validación avanzada (duplicados, longitud)

## Acceptance criteria
- [ ] Mostrar título
- [ ] Input con label y botón para agregar
- [ ] Mostrar lista y permitir eliminar cada usuario
